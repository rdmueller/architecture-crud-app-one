== Fehlerbehandlung

=== Fehlerklassifizierung

[cols="1,3,2", options="header"]
|===
| Fehlertyp | Beschreibung | Behandlung
| Validierungsfehler | Ungültige Eingabedaten | 400 Bad Request mit Details
| Schema-Fehler | Daten entsprechen nicht dem JSON-Schema | 422 Unprocessable Entity
| Nicht gefunden | Ressource existiert nicht | 404 Not Found
| Systemfehler | Unerwartete Exceptions | 500 Internal Server Error + Logging
|===

=== Fehlerbehandlungsstrategie

```python
@app.exception_handler(ValidationError)
async def validation_exception_handler(request, exc):
    return JSONResponse(
        status_code=400,
        content={"detail": exc.errors()}
    )

@app.exception_handler(FileNotFoundError)
async def not_found_handler(request, exc):
    return JSONResponse(
        status_code=404,
        content={"detail": str(exc)}
    )
```

== Persistenz

=== JSON-Schema-Validierung

Alle Daten werden vor dem Speichern gegen das definierte JSON-Schema validiert:

```python
def validate_data(data: dict) -> bool:
    with open('schema.json') as f:
        schema = json.load(f)
    
    try:
        jsonschema.validate(data, schema)
        return True
    except jsonschema.ValidationError as e:
        raise ValueError(f"Schema validation failed: {e}")
```

=== Transaktionsmanagement

Pseudo-Transaktionen durch Backup vor Schreiboperationen:

```python
def save_with_backup(data: dict, filepath: str):
    # Backup erstellen
    if os.path.exists(filepath):
        backup_path = f"{filepath}.backup"
        shutil.copy2(filepath, backup_path)
    
    try:
        # Daten speichern
        with open(filepath, 'w') as f:
            json.dump(data, f, indent=2)
    except Exception as e:
        # Rollback bei Fehler
        if os.path.exists(backup_path):
            shutil.move(backup_path, filepath)
        raise e
```

== Logging

=== Log-Level

* **DEBUG**: Detaillierte Entwicklungsinformationen
* **INFO**: Allgemeine Betriebsinformationen
* **WARNING**: Nicht-kritische Probleme
* **ERROR**: Fehler die behandelt werden
* **CRITICAL**: Kritische Fehler die zum Absturz führen

=== Log-Format

```python
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(name)s - %(levelname)s - %(message)s',
    handlers=[
        logging.FileHandler('app.log'),
        logging.StreamHandler()
    ]
)
```
